# Styles, integrity and iteration

## Choosing a style

If the user has not chosen a visual direction, propose 5 to 7 that are **genuinely different**, not the same layout with new names. Fit them to the brand: read the "style fit" note in the brand profile, and for a client with no such note judge from their logo, colors, audience and tone. Say briefly which ones read as on-brand and why, and let the user pick. Do not force a historical style when a modern equivalent would be clearer.

A starting menu:

1. **Modern Letterpress / Stamp**
   - inked or engraved shapes
   - limited palette
   - tactile, dimensional print character
   - controlled imperfections

2. **Memphis / 80s postmodern**
   - bold geometric shapes
   - playful, tactile forms
   - bright limited palette
   - asymmetric, energetic layout

3. **Japanese Minimal**
   - restrained composition
   - large negative space
   - one strong graphic element
   - careful typography

4. **Cut Paper / Collage**
   - hand-cut or painted shapes
   - irregular, tactile edges
   - layered composition

5. **Bauhaus / Modernist**
   - geometric shapes
   - asymmetric hierarchy
   - bold sans-serif typography
   - limited high-contrast palette

6. **Swiss / International Typographic**
   - strict grid
   - strong alignment
   - generous whitespace
   - typography-led

7. **Risograph**
   - limited ink palette
   - grain and print texture
   - bold shapes
   - slight registration imperfections

Other directions that can work: Brutalist graphic, Wayfinding / signage, contemporary editorial, monochrome plus a single accent, contemporary indie festival, vintage screen print, Mexican modernist graphic design, photocopied punk / fanzine, retro-futurist, scientific diagram, geometric constructivist.

Every poster needs one clear visual concept, chosen on purpose.

## Style integrity

Once a style is selected:
- Keep the visual language coherent.
- Do not mix unrelated styles merely to add decoration.
- Do not invent additional copy.
- Do not let style override factual readability.
- On a revision, keep the selected style unless the user asks for a new direction.

## Iteration: read feedback as design changes

| The user says | Do this |
|---|---|
| "Está muy cargado" | Reduce elements, increase whitespace, simplify the hierarchy. |
| "Se ve muy pequeño" | Enlarge the essential text and remove secondary information. |
| "Hazlo más llamativo" | Strengthen contrast, scale, composition or color. Do not automatically add decorations. |
| "No parece de mi negocio" | Keep the brand's assets, colors and identity. Check that the right logo file is really the one placed and that nothing from another brand leaked in. |
| "Quiero otro" | Offer a substantially different direction, not a minor variation. |
| "Para WhatsApp" | Recompose for 9:16; do not crop the print version. |
| "Para imprimir" | Recompose for the print size and its safe margins. |

If the user asks for another style, regenerate with the same facts unless they give new content.

## Inspiration and attribution

The approach is inspired by John Hartnup's June 7, 2026 article "AI-generated posters don't have to be horrible" (https://john.hartnup.uk/2026/06/07/ai-event-posters.html) and his poster prompts catalogue (https://john.hartnup.uk/poster-prompts/). The central idea is to avoid the generic, repetitive AI-poster look by deliberately choosing a distinctive direction; his examples include Bauhaus, Swiss Style, Risograph, Cut Paper, Brutalist, 90s Rave, Memphis, Japanese Minimal, Wayfinding, Stamp / Letterpress and others. Use both as inspiration; do not reproduce either verbatim.
